# 固定风格与可复核导出

## 生成 HTML

先取得本次风格选择，按 `styles.md` 组织 `body.html` 和 `map.html`。正文与材料放在任务 `work/`；原材料解析结果可复用，修改时只改受影响模块。以下入口保留既有参数，新增必填 `--style`，有意取消隐含默认风格：

```powershell
python '<skill-dir>/scripts/render_notes.py' --body '<body.html>' --map '<map.html>' --title '<title>' --subtitle '<subtitle>' --style cornell --output '<task-dir>/outputs/notes.html'
```

六种 ID 为 `cornell / outline / annotated / sketch / handwritten / electronic`。脚本读取模板与布局，检查所选结构的存在、重复锚点、悬空链接和部分资源问题。输出 HTML 内嵌风格与资源清单，同目录的 `notes.manifest.json` 记录内容、模板与 HTML 哈希及本机已知字体指纹。清单只证明机械一致性，不代替用户选择或内容审核。布局类存在也不证明教学合理。

HTML 没有风格按钮、URL 切换或本地存储覆盖。修改风格须重新生成一个版本。使用自足内联 CSS、MathML、SVG 或 data:image；外部引用链接可以保留，但图片、字体 CSS 与脚本不能依赖网络才能显示。

作者正文与地图只接受脚本中明确允许的静态标签、属性和 URL；事件属性、主动跳转、SVG 动画和作者脚本会被拒绝。不要删除校验来容纳不支持的内容，应改为静态表达。模板打印脚本由独立的 CSP 哈希授权，作者内容不会获得脚本执行权限。PDF 导出也检查主动内容；旧文档若包含自定义脚本，需要重新生成并审阅。

## 公式、图示与语义检查

- 公式使用 MathML，保留原始 TeX（如 `data-tex`）或工作公式清单。使用已验证转换器时，核对不支持的环境；没有 merror 不等于没有丢符号。逐项查看上下标、矩阵行列、分数、括号、正负号及量词条件。
- 同一符号的定义与适用域一致；关键推导有中间步骤。可精确计算的导数、矩阵或数值例题用现有本地计算工具交叉核验，抽样和数值点检不能证明一般定理。正文、例题、自测依赖和地图关系分别人工判断。
- 关键原图登记来源与实际覆盖位置，判断能否忠实重绘；源图缺失不得伪造原图。新增曲线由已核对方程计算，检查轴、单位、尺度、图例和箭头。每个有学习意义的图都有 alt 与相邻解释；装饰图不能替代必要原图。
- 必要图静态内嵌，不以 canvas、未完成的 Mermaid、懒加载远程图片或运行时模型调用作为交付。互动图可以另附，但正文必须有同义的打印静态图。
- 代码 HTML 转义，保留字面字符、缩进与换行。窄屏允许局部横向滚动；打印按语义断行且无裁切。过宽公式分行、跨栏或拆块，不删除项；长代码允许分页。
- 自测用 `<details class="answer"><summary>答案与理由</summary><div class="answer-body">…</div></details>`；打印前全部展开，打印后恢复原状态。所有 h2/h3 有稳定 id。
- 屏幕验证实际所选版式、390px 窄屏、目录与地图链接、答案开合；核心解释不藏进折叠。不要在未选风格时用经典手写兜底。

## 从确认版本导出

先交付 HTML，等待内容确认；本次明确要求 PDF 时按已确认范围执行，不重复询问。确认记录包含 HTML SHA256；算出哈希本身不是用户确认。

```powershell
$notesHash = (Get-FileHash -LiteralPath '<confirmed.html>' -Algorithm SHA256).Hash.ToLowerInvariant()
python '<skill-dir>/scripts/export_pdf.py' '<confirmed.html>' --output '<notes.pdf>' --approved-sha256 $notesHash --work-dir '<task-dir>/work'
```

新文档自动读取锁定风格；可选的 `--style` 仅断言一致性，冲突即拒绝。旧版双风格 HTML 为兼容保留：必须显式传入当时审阅的 `--style handwritten` 或 `electronic`，不猜测旧稿的选择。

渲染使用 Python 标准库；导出使用本机 Chrome/Edge、现有 `websocket-client`（等待资源与检查打印）和 `PyMuPDF`（验证书签及链接）。不增加服务、模型 API 或全局配置。缺依赖时先检查现有 PDF 验证环境；确实缺失才在独立环境安装，不静默跳过检查。字体指纹绑定当前生成环境，跨机或字体更新后需重新渲染审阅；没有字体文件记录的平台仍需人工核对字体。不承诺跨平台像素完全一致。

脚本在隔离浏览器中禁止外部 HTTP 资源，等待本地字体与内嵌图片，核对公式／图像／答案数量，展开答案，检查打印宽度与不可分页块尺寸；使用同一份 HTML 打印并生成原生书签。Chrome 的命名跳转可能忽略页边距，脚本按正确定位的原生标题书签规范化为直接页内链接；正文链接应指向 h2/h3 或以其开头的章节容器，其他目标需先调整为明确的标题锚点。哈希、风格、资源、字体、溢出、书签或链接目的页检查失败，停止交付。已有 PDF 不覆盖。输出旁的 `.verification.json` 记录实际浏览器、页数、哈希与机械检查范围。

## 导出后的交付门槛

逐页渲染 PDF 查看，不只检查抽出的文字。检查公式、图线与图例、两栏阅读顺序、长代码、跨页关系、孤立标题、页边界及每道答案；对照 HTML 的必要内容和原材料覆盖清单。核对书签名称及目标内容，抽查地图和正文跳转，不能只凭页编号在范围内断言正确。

自然分页，不能为压页数漏掉必要图片。纯排版问题回到 HTML 修复并重新生成关联清单；改变公式、事实或讲解则重新交内容审阅。正式课程 PDF 未经确认不交付；修改工具时可以用明确标注的合成或真实材料摘录做内部导出测试。Goodnotes 实际导入未测时如实说明。

分开报告来源完整性、内容／逻辑判断、机械转换保真、实际视觉检查。任何单项通过都不能宣称绝无错误或跨材料、跨模型稳定保证。
